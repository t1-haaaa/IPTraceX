# Timeline

Repeated investigations of the same target form a history
(`HistoryFor`), rendered as `INTELLIGENCE TIMELINE`: timestamped
snapshots (country, region, city, ASN, ISP, organization, prefix, PTR,
VPN, proxy, Tor, hosting, risk, confidence) plus consecutive `CHANGES`.

Change wording is neutral: `CHANGE DETECTED`, never `ATTACK DETECTED`.
A GeoIP change does not prove movement — databases, providers,
reassignments and BGP evolve constantly (stated in every timeline).
