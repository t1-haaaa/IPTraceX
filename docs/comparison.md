# Comparison

```bash
./iptracex.sh --compare IPX-20261001-ABC123 IPX-20261008-DEF456
./iptracex.sh --compare-ip 1.1.1.1 8.8.8.8
```

Field-by-field tables (`INVESTIGATION COMPARISON`, `IP COMPARISON`)
with per-field `CHANGE DETECTED` markers and a changed-field count
(including risk deltas as plain numbers, e.g. both scores side by side).
